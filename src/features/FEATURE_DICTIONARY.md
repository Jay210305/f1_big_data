### 2. `driver_style.parquet` — style profile (Model 2)

One row per `(season, driver)` (~100 rows). Mean & std across laps of:
throttle_mean/std/modulations/active_frac, brake_frac/event_count/intensity,
speed_mean/std, gear_mean/std, rpm_mean, lat_g/long_g/vert_g stats,
lat/long load integrals, dirty_air_frac.

### 3. `stint_degradation.parquet` — stint curves (optimizer)

One row per stint (~50k rows). Keys: `season, gp, session, driver, stint`.

| Feature | Description | Leakage for RUL? |
|---------|-------------|------------------|
| compound, stint_length, max_life | compound, total laps, max tyre age | **YES** (outcome) |
| pace_start, pace_end | first / last laptime of stint | outcome |
| pace_decay_end | final laptime_delta_stint_start | outcome |
| had_cliff, cliff_laps | whether a cliff occurred | outcome |
| mean_lap_delta | avg lap-to-lap delta | outcome |
| degradation_slope | (pace_end−pace_start)/(stint_length−1) | outcome |
| stint_track_temp, stint_rain | env during stint | OK |
| stint_lat_load, stint_long_load | avg mechanical load | OK |

## Leakage policy

- For **RUL prediction (Model 1)**, use only `lap_features` rows with features
  marked OK, and **exclude** `stint_length / max_life / pace_end / pace_decay_end
  / had_cliff / degradation_slope` (those are stint outcomes / the label).
- `life` (tyre age so far) is **allowed** — it is known at prediction time.
- All `laptime_delta_*` and `cliff_flag` use only the current and past laps of
  the stint (no future information).
- `stint_degradation` is for analysis and the optimizer simulator, not for
  per-lap RUL features.
